# BuildWise 文档索引

当前仓库只保留仍然有效、会被继续维护的主干文档。  
执行版文档用于约束当前实现和后续变更；历史思考稿仅用于理解产品演进背景，不作为当前事实依据。

## 阅读顺序

如果你第一次进入本仓库，建议按以下顺序阅读：

1. 对外定位与主实现入口
2. 执行版产品与架构基线
3. 项目操作手册
4. 运行与投产文档
5. 历史思考与商业材料

## 8. 文档使用原则

1. 对外口径优先看根目录 [README.md](../README.md)。
2. 当前实现事实优先看 [v2/README.md](../v2/README.md) 和 [v2/backend/README.md](../v2/backend/README.md)。
3. 产品、架构、模型、追溯和治理规则优先看本目录中的执行版文档。
4. 运行、投产和放行条件优先看 `v2/backend/docs/**`。
5. 历史材料可以阅读，但不应覆盖执行版结论。
6. 新增执行版文档必须具有明确职责，不能与现有文档重复。
