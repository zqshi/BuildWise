# 统一项目模型最小结构

## 目的
定义可落地的最小统一项目模型（UPM），用于承载实体、字段、规则与页面的核心关系，支撑生成与同步。

## 最小结构（MVP）

### 1. 实体（Entity）
- `id`: 全局唯一
- `name`: 业务名称
- `description`: 说明
- `fields`: 字段列表

### 2. 字段（Field）
- `id`
- `name`
- `type`: `string | number | boolean | date | enum`
- `required`: `true/false`
- `default`: 默认值
- `rules`: 规则引用列表

### 3. 规则（Rule）
- `id`
- `target`: 作用对象（字段/页面/组件）
- `type`: `required | range | pattern | visibleIf | compute`
- `params`: 规则参数
- `message`: 提示文案

### 4. 页面（Page）
- `id`
- `name`
- `route`: 路由
- `layout`: 布局类型
- `components`: 组件树引用

## 关系约束
- 页面引用实体（CRUD 页面）
- 组件绑定字段（表单/表格）
- 规则挂载字段或页面组件

## 最小示例（JSON）

```json
{
  "entities": [
    {
      "id": "entity_product",
      "name": "Product",
      "fields": [
        {
          "id": "field_price",
          "name": "price",
          "type": "number",
          "required": true,
          "rules": ["rule_price_gt_0"]
        }
      ]
    }
  ],
  "rules": [
    {
      "id": "rule_price_gt_0",
      "target": "field_price",
      "type": "range",
      "params": { "gt": 0 },
      "message": "价格必须大于 0"
    }
  ],
  "pages": [
    {
      "id": "page_product_list",
      "name": "产品列表",
      "route": "/products",
      "layout": "table",
      "components": ["table_products"]
    }
  ]
}
```
