# 代码结构

## 目的
明确代码布局与职责边界，降低维护成本。

## 根目录

- `docs/`：产品与技术文档
- `v2/`：当前迭代（前端 + 后端）
- `autoboot/`：自举流水线

## v2 结构

- `v2/`
  - `index.html`：前端入口
  - `src/`：前端源码
  - `backend/`：后端服务

## v2/backend 结构

- `backend/src/`：Fastify 服务实现
- `backend/README.md`：本地运行说明

## 约束
- 前后端均采用 TypeScript
- 前端 API base 通过 `VITE_API_BASE` 配置
- 后端端口默认 `5055`
