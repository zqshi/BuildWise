## 版本目标

当前 BuildWise 的「分析→交付物→测试→发布」是单维度整体链路，domain 模型没有「目标端」轴。多端项目（web + iOS + Android + 鸿蒙）下，整体 `go` 掩盖单端短板——web 端测试撑高整体 passRate、agent 改 web 路径即「边界内完成」，原生端零覆盖被合法掩盖，迭代标记「可发布」但只有 web 端真实可投产（虚假推进）。

本版本引入「目标端」一等维度，让发布评审按端分别给 decision/blockers，整体可发布 = 各声明端均 `go`，在门禁层堵死虚假 go。能力边界：BuildWise 不替代各端 CI/构建，本期「真实投产可用」= 交付物归属端 + 该端测试通过 + 该端代码改动落地 + 门禁按端聚合，不接各端构建链（留后续）。

## 版本验证标准

1. 项目可声明目标端集合（`targetPlatforms`），默认 `["web"]` 向后兼容；
2. 发布评审对每个声明端分别给出 `decision/blockers`，顶层 `decision` 由规则聚合（有 block→block / 全 go→go / 否则 caution）；
3. publish 门禁：任一声明端缺失或非 `go` → 整体不可发布并返回阻断原因（虚假 go 被堵）。

## 版本范围

**做什么:**
- domain：TargetPlatform 枚举 + Project.targetPlatforms + 交付物 targetPlatform + releaseReview.perPlatform（顶层 decision 改聚合）
- application：releaseReview LLM 按端评审（governanceRunnerOps）+ 解析（releaseReviewOps）+ 聚合（qualityOps）+ finalize 透传 + publish 门禁「各端均 go」
- infrastructure：迁移 008 + Project 持久化读写 targetPlatforms
- interfaces：Project 创建/更新 schema 接受 + 校验 targetPlatforms
- 前端：项目设置端声明 + 发布评审按端展示
- 测试：新增 perPlatform 聚合 + 门禁单测，适配 ~15 个既有测试

**不做什么:**
- 测试矩阵 generatedTestMatrix 按端分组 coverage/passRate → v0.30.0
- 代码路径 codePathWhitelist/boundaryCodePaths 按端白名单 → v0.30.0
- 各端 CI/构建链接入（超出 BuildWise 边界）→ 按需
