## 版本目标

实现选定的编码 agent 适配器 ClaudeCodeCliAdapter，通过 mock spawn 契约测试验证端口契约，不接真实 claude CLI、不改 codeRewrite。这是 V2.2 的低风险第一步，为 v0.8.2 codeRewrite 改造打基础。

## 交付内容摘要

| 文件 | 内容 |
|------|------|
| `infrastructure/agent/adapters/claudeCodeCliAdapter.ts` | ClaudeCodeCliAdapter 实现 CodingAgentAdapter 端口。spawn `claude -p <instruction> --output-format stream-json --add-dir <repoPath>`，按行解析 stream-json，tool_use(Edit/Write/MultiEdit/NotebookEdit) 提取 changedPaths（转相对路径）。依赖注入 spawnFn（生产真实 spawn，测试 mock）。state 持有 timer，finalize/cancel/close 时 clearTimeout 防进程 hang |
| `backend/tests/claude-code-cli-adapter.test.mjs` | 8 契约测试：端口满足、start 参数（-p/stream-json/--add-dir/cwd）、running→completed 状态、getEvents 解析 tool_use→changedPaths、since 游标、cancel、getStatus-not-found、instruction 传入 |

## 关键技术决策表

| 决策 | 理由 |
|------|------|
| spawnFn 依赖注入 | 生产用 child_process.spawn，测试注入 mock 伪子进程，不真实跑 claude（零成本零风险） |
| stream-json 按行解析 | 每行 JSON.parse，映射 assistant/tool_result/result 事件，tool_use 从 input.file_path 提取 changedPaths 并转相对 repoPath |
| --allowedTools 限制 Edit/Write/MultiEdit/NotebookEdit | 降低 agent 越权风险，但最终边界由调用方事后 git diff + assertBoundaryWhitelist 校验（v0.8.2） |
| state.timer + clearTimeout | spawn 默认 10 分钟超时会令测试进程 hang，finalize/cancel/close 时 clear |
| spawn 类型双重断言 | 真实 spawn 的 ChildProcess kill 签名（number\|Signals）比 SpawnFn 结构类型窄，TS 参数逆变不兼容，用 `as unknown as SpawnFn` 转换 |

## 遗留问题

- stream-json 事件格式的精确性基于 Claude Code 已知格式（assistant/tool_use/tool_result/result），v0.8.2 真实 dryRun 实跑时需校验格式是否与 mock 一致，必要时微调 mapStreamEvent
- 适配器未注册到 AgentRegistry（app bootstrap 注册留 v0.8.2，与 codeRewrite 改造一起接通）

## 对后续版本的约束

- **v0.8.2 待做**：app bootstrap 注册 ClaudeCodeCliAdapter 到 AgentRegistry；codeRewriteJobOps 异步封装；codeRewriteOps 改造（registry.create → 轮询 → git diff → 事后边界校验）；路由改异步；dryRun 实跑验证
