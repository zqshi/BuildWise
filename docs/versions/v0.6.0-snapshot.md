## 版本目标

建立参照 arc 的版本化迭代声明纪律（docs/versions + 任务依赖表 + 质量检测协议），并清理 3-22 后遗留的 Skill 系统空壳死代码与 openclaw 命名耦合。这是后续 V2（Agent 解耦）/V3（门禁硬化）/V4（本体沉淀）的地基——先立规矩再动核心架构，确保高质量推动落地。

## 版本验证标准

1. `docs/versions/` 下有且仅有一个 `*-current.md`（`check-version-discipline.mjs` 通过）
2. 删除 Skill 死代码后 `tsc --noEmit` 零错误、既有测试全绿、新增「无 skillChain 仍能引导」测试通过
3. coach 层无残留 openclaw 字样（命名中性化）

## 版本范围

**做什么:**
- 建立 docs/versions 版本化机制（TEMPLATE + current + backlog）
- 移植 arc 版本完成质量检测协议（6 项）

- 改造调用方 coachOps.ts / gitIntakeOps.ts，Coach 引导完全由 stageAgents + replyGuard 承担
