## 关键技术决策

| 决策 | 理由 |
|------|------|
| fullCycleService 用提取 const + 三元收窄（非 `?.`） | delegates.X 期望非 undefined 返回类型，`?.` 返回 `| undefined` 不匹配（tsc 报错）；提取 const 后 TS 4.4+ 闭包收窄，三元保证非空调用 |
| sqlite findXxx(id) 用 throw 兜底 | 刚插入 id 查回应非空，throw 是类型守卫（不应触发），比 `!` 安全（运行时检查 + 类型收窄） |
| 数组索引 `!` → `if (!x) continue` 守卫 | 循环边界/匹配索引已守卫但 TS 不推断；continue/throw 收窄，行为不变（原 `!` 路径永不 undefined） |
| DEPLOY.md 独立文档 | docker-compose 未显式注入鉴权变量，依赖 .env 派生但无文档说明；DEPLOY.md 明确生产配置派生与 fail-fast 守卫，避免误用开发 .env 部署 |
