# v0.22.0 Snapshot — owner 分支收敛重新设计

> 状态: 已归档（2026-06-28）
> 起始 commit: 1e2a372 (2026-06-28)
> 上一版本: [v0.21.0](v0.21.0-snapshot.md)

## 版本目标
v0.18.0 T3 owner 收敛方案B revert（删 ensure*Access owner 块 + 加 platformOwner 旁路，但 dev/契约 authRole=owner 无 platformRoleBinding 旁路不触发 → 403）。本版重新设计：保留 owner 块 + resolveTenantRole 加 isPlatformOwner 旁路，区分「真超管 platformRoleBinding」与「dev 默认 owner」语义，不破坏 dev/契约场景，保持租户隔离。

## 交付内容摘要
- **T1 探路 owner 语义 + 设计方案**（done）：坐实三类 owner 语义（真超管 platformRoleBinding / dev owner AUTH_MODE=off / 租户 owner resolveTenantRole）；核心矛盾：owner 块只放行无 tenantId 项目，有 tenantId 项目走 resolveTenantRole 无旁路 → 真超管跨租户 403；方案B 错误根因：删 owner 块致 dev owner 失放行 403。
- **T2 实现 owner 收敛（TDD）**（done，commit 7b03de2）：tenantAccess.ts 加 `isPlatformOwner(repo, userId)`（platformRoleBinding role=owner/admin），resolveTenantRole 顶部旁路 `return "admin"`；owner 块（workspaceRouteUtils.ts）保留不动，修正方案B 删块覆辙。三类 owner 语义收敛。
- **T3 归档验证**（done）：verify:all 全绿；6 项质检全过。

## 关键技术决策表
| 决策 | 选择 | 理由 |
|---|---|---|
| owner 收敛策略 | 保留 owner 块 + resolveTenantRole 加 isPlatformOwner 旁路 | 方案B 删 owner 块致 dev owner(AUTH_MODE=off)失放行 403；保留块让 dev owner 走块、真超管走旁路，各走各路 |
| 真超管识别 | platformRoleBinding role=owner/admin | 等价 LEGACY_ROLE_MAP admin→owner 语义；admin 兼容历史绑定 |
| 旁路位置 | resolveTenantRole 顶部 | 统一租户角色解析入口，projectAccess/iterationAccess/listAccessibleTenants/listProjectsForUser 均受益 |
| owner 块处理 | 不动 | workspaceRouteUtils 的 owner 块只放行无 tenantId 项目(dev owner)，是有意保留的 dev/契约放行路径 |
