## 版本目标

v0.30.0 让 `releaseReview.perPlatform` 数据流入前端按端展示（编造防控 + 两链对齐 + UI 就绪），但端到端链路仅在单元测试 + mock 层验证（670 测试 0 fail），**从未在真实环境跑通**。本版本在真实环境实跑声明多端项目 → 分析附件 → LLM 按端评审产出 perPlatform → 前端按端渲染全链路，验证 v0.30.0 交付在真实环境有效，修复实跑暴露的真实问题。

性质：验证 + 按需修复，非新功能开发。
