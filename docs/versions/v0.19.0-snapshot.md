## 版本目标
v0.18.0 调研坐实两个根本性架构问题：①迭代对话是阶段驱动的确定性编排，不识别用户「询问」意图，每次对话无条件合成交付物+推进阶段——「运行态（对话）与执行态（产交付物/推进）未分离」；②fullCycle 全流程的编码步骤（frontend-rewrite/backend-rewrite）走 `llmCodeRewriteOps`（LLM 同步生成），未接真实 codingAgent，核心价值闭环（编码改动回流本体）在生产流程断裂。本版本根治：迭代对话接入意图识别分离运行/执行态；fullCycle 编码步骤改接真实 codingAgent（引入 OpenHands adapter）。

## 交付内容摘要
- **T1 迭代对话意图识别 + 运行/执行态分离**（done）：`orchestrateCoachMessage` 加 `isConversational` 分支——`finalIntent ∈ {general, question}` 时跳过 `attemptArtifactSynthesis` + `evaluateAndAdvanceStage`（纯对话不产交付物不推进），仅推进类才合成+推进。`VALID_INTENTS` 加 `question`，stageAgents prompt 引导。复用现有 LLM marker intent 机制，不额外加 classifyIntent 调用。
- **T2 OpenHands adapter + 部署拓扑 + 端到端验证**（done）：`openHandsAdapter.ts` 实现 CodingAgentAdapter 端口（HTTP REST，httpFn 注入），app.ts 条件注册（OPENHANDS_BASE_URL 配了才注册）。**修正接续点旧调研 6 处错误**（端口 18000/X-Session-API-Key/api 前路径/conversation 作用域事件/`/alive`+curl healthcheck/Anthropic 兼容 LLM）。docker-compose 加 openhands service + repo-init 卷权限修正。端到端验证：agent 5s 真改 `src/Button.tsx`（Submit→登录）+ git diff 回流。
- **T3 fullCycle 编码步骤接真实 codingAgent**（done）：`qualityService.rewriteCodeInBoundaryViaAgent`（复用 `executeCodeRewriteViaAgent` + 适配 `IterationCodeRewriteResponse` + 本体回流），`workspaceService` delegates.rewriteCodeInBoundary 切换为 agent 优先 + LLM 降级，app.ts 从 env 读 `BUILDWISE_CODING_AGENT_TYPE`（默认 openhands，isAvailable 校验）。dryRun 走 LLM（codingAgent 无法 dryRun 预演）。复用 fullCycle 既有后台 job，单步 await 不阻塞 HTTP。

## 关键技术决策表
| 决策 | 选择 | 理由 |
|---|---|---|
| 意图识别机制 | 复用 LLM marker intent，general/question 跳过合成+推进 | 不额外加 classifyIntent LLM 调用；general 兜底也跳过更安全 |
| OpenHands 接入方式 | HTTP REST adapter（非 Python SDK/非 OpenAI 兼容网关） | TS 后端不嵌 Python runtime；拿结构化 tool_use/tool_result 事件 |
| OpenHands LLM 接口 | Anthropic 兼容（与 BuildWise .env 同源） | 实测智谱 GLM 走 /api/anthropic + model 带 litellm anthropic/ 前缀可用 |
| fullCycle 接 codingAgent | 复用既有后台 job，单步 await agent | fullCycle 整体已在后台 job，无需嵌套异步轮询 job（接续点误判） |
| dryRun 语义 | dryRun 走 LLM fallback | codingAgent 无法 dryRun 真改代码，预演走 LLM 合理 |
| agent 优先 + LLM 降级 | 有 registry 且非 dryRun 走 agent | 对称 handleCodeRewrite 范式；无 registry/dryRun 降级 LLM |
