| 决策 | 选择 | 理由 |

| tenantId 来源 | 认证态(authTenantId‖userId‖default) | 堵 query/body 伪造数据串，租户身份只从认证上下文 |
| changeImpact 路径映射 | 含 backend→backend-code,否则 frontend-code | 简单可靠,主场景(.tsx前端)正确,消除误伤 |

| fullCycleOps 拆分 | 常量/checkpoint/本体三层 + re-export 导出符号 | 保持 fullCycleSteps/fullCycleService import 兼容 |
