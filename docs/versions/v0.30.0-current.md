# v0.30.0 Current — 按端质量数据 + LLM 按端评审

> 状态: 进行中

> 上一版本: [v0.29.0](v0.29.0-snapshot.md)

## 版本目标

v0.29.0 引入「目标端」维度并堵死虚假 go（门禁端级聚合），但 LLM 按端评审（T3）因缺按端真实质量数据转后续。本版本补齐按端质量数据（测试矩阵按端分组 + 代码路径按端白名单），让 LLM 按端评审有真实依据，`releaseReview.perPlatform` 数据流入前端按端展示（v0.29.0 T6.7 UI 已就绪待数据）。

## 版本验证标准

1. 测试矩阵 generatedTestMatrix 按声明端分组，每端有 coverage/passRate；
2. 代码路径 codePathWhitelist/boundaryCodePaths 按端白名单，agent 改动按端归属校验；
3. releaseReview LLM 按端评审产出 perPlatform（每端 decision/blockers 有按端数据依据），前端按端展示生效（不再降级整体展示）。

## 版本范围

**做什么:**
- 测试矩阵 generatedTestMatrix 按端分组（coverage/passRate per platform）
- 代码路径 codePathWhitelist/boundaryCodePaths 按端白名单
- T3（v0.29.0 转入）：synthesizeReleaseReviewOp 按 targetPlatforms 对每端出 decision/blockers + domain releaseReview 产出 perPlatform + 解析/校验链
- 前端按端展示数据接入（v0.29.0 T6.7 UI 已就绪，perPlatform 数据流入即生效）

**不做什么:**
- 各端 CI/构建链接入（超出 BuildWise 边界）→ 按需

## 对后续版本的约束

- 按端质量数据（测试矩阵/代码路径）为 T3 LLM 按端评审的必要前置，不得在数据未齐备时让 LLM 编造按端结论（v0.29.0 T3 转后续的教训）；
- perPlatform 数据须有按端真实依据（测试覆盖/代码归属），非 LLM 推断；
- TargetPlatform 固定枚举不变，新增端加枚举值。
