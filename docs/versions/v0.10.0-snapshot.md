## 关键技术决策表

| 决策 | 理由 |
|------|------|
| 回流桥纯函数不可变 | mergeCodeRewriteIntoOntology 不改原 KB，返回 updatedKb + mergedPaths，与 extractKnowledgeBaseUpdateOp 风格一致，可测 |
| codeMap 前缀匹配合并 | edit.path 与已有 codePaths 前缀目录匹配则合并进已有 capability，否则新增「编码改写记录」项，避免碎片化 |
| 定时扫描默认关 | runExperienceScan 消耗 LLM 额度，BUILDWISE_EXPERIENCE_SCAN_ENABLED=0 默认关，启用后受 scheduleScanEnabled policy + intervalHours 二次控制 |
| 前端 isNew 标记纯函数可测 | mergeToUnifiedGraph 接 previousNodeIds 标记，4 测覆盖；调用方接入数据源即激活（V4 遗留） |
| continuousModeling diffSnapshots 已接通 | T1 确认 diffSnapshots 在 continuousModelingWorkspaceService:167 真调用（本体快照版本 diff），T2 回流让快照有内容可 diff，链路闭环 |
