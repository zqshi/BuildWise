## 版本目标
承接 v0.15.0 体检待修遗留 4 项：T2b 停止按钮 UI + T5 policyGate 治理盲区 + T6 changeControl 与 fullCycle checkpoint 双状态解耦 + T7 FullCycle Job 重启恢复 + changeImpact 集成。

## 交付内容摘要
- **T2b fullCycle 停止按钮 UI**：ChatContext 加 fullCycleJob 上提+drilling+停止按钮（取消能力后端 v0.15.0 已就绪，补前端入口）；shouldShowStopButton 双条件纯函数。
- **T5 policyGate 分级门禁接入 fullCycle**：①stale 制品过时 ②缺必要制品 → 阻断；③缺人工确认 → 记审计不阻断（与 autoConfirm 全自动定位一致）。新增 evaluatePolicyGateForFullCycleOp 分级 + collectPolicyGateResults（非短路）；coach 路径短路语义不变。
- **T6 changeControl 与 fullCycle checkpoint 双状态互查**：正向 sync（步骤完成→artifact outputVersion+gateStatus=passed 同步，syncArtifactForFullCycleStepOp 幂等避 markDownstreamStale 副作用）+ 反向互查（推进前查 artifact gateStatus blocked 阻断）。STEP_ARTIFACT_MAP 映射。
- **T7a 中断任务一键续跑入口**：POST /full-cycle/retry 别名路由 + 前端 InterruptedFullCycleBanner"一键续跑"按钮（fullCycle job 纯内存，恢复靠 checkpoint 落盘，不标 job failed）。
- **T7b changeImpact 集成 fullCycle + 修检测**：改写步骤后用 rewriteInstruction 调 changeImpact 检测，命中→markCodeArtifactsStaleOp 标代码 artifact stale→联动 T5 stale 阻断下游；检测去 2-gram + 去反向包含减误报 + 精确匹配补 2 字短术语召回。

## 关键技术决策表
| 决策 | 选择 | 理由 |
|---|---|---|
| policyGate 阻断语义 | 分级（①②阻断③记审计） | fullCycle 全自动 autoConfirm 无人确认，③不阻断与定位一致 |
| 双状态互查方向 | 正向 sync + 反向 blocked | fullCycle delegate 不 commit artifact，需显式同步+互查 |
| gateStatus=passed 全自动 | lastConfirmedBy="full-cycle" 区分 | 接受虚标但区分来源（人工 vs 全自动） |
| sync 不走 commitIterationArtifactOp | 直接更新 item | 避免 markDownstreamStale 副作用致 fullCycle 自阻断 |
| changeImpact 集成阻断 | 标 stale 联动 T5 | 复用 T5 stale 机制，避免新建阻断路径 |
| fullCycle job 重启 | 纯内存 + checkpoint 续跑 | 与 Analysis 持久化不同，不标 job failed |
| changeImpact 检测改进 | 去 2-gram + 精确匹配 | 减短词误报 + 补短术语召回 |
