# Snapshot 模板 (版本完成后)

版本完成时，删除 "任务详情" 和 "实施要点" 等执行细节，只保留:
1. 版本目标
2. 交付内容摘要
3. 关键技术决策表
4. 遗留问题
5. 对后续版本的约束
6. 质量检测结果（6 项检测摘要）

---

# 版本完成质量检测协议（每版本归档前必执行）

| # | 检测项 | 方法 | 性质 |
|---|--------|------|------|
| 1 | 死代码与孤立文件 | 检查文件是否被 import 或有 script 入口 | 必修 |
| 2 | 依赖卫生 | 每个 dep 在 src 中有 import | 必修 |
| 3 | 配置一致性 | runtimeConfig ↔ .env.example 双向对齐 | 必修 |
| 4 | 文档对齐 | CLAUDE.md/CONTRIBUTING 路径存在 | 必修 |
| 5 | 架构合规 | DDD 分层 + 循环依赖 + 文件≤800行 + 函数≤60行 | 必修 |
| 6 | 仓库卫生 | gitignore 完备，无构建产物入库 | 必修 |

执行命令：
```bash
cd v2 && npm run check:hygiene && npm run check:boundaries
cd backend && npx tsc --noEmit && cd .. && npx tsc --noEmit
node scripts/check-version-discipline.mjs
```
必修项全过才能归档 snapshot。未过项记入本文件 `## 遗留` 并在 backlog 标技术债务。
