## 关键技术决策表

| 决策 | 理由 |
|------|------|
| buildArgs 加 --verbose | claude CLI 2.1.177 `-p`+`stream-json` 必需 --verbose，否则 exit=1 零输出（实跑暴露，mock 测不到） |
| buildArgs 加 --permission-mode bypassPermissions | headless 模式 Edit/Write 需免权限确认；配合 --allowedTools 限制工具集为编辑类白名单，bypassPermissions 在受限工具集下安全 |
| mapStreamEvent 加 type:"user" 分支 | 真实 stream-json 的 tool_result 内嵌在 type:"user" 的 message.content，非顶层 type:"tool_result"（adapter 原假设错误，mock 样本与真实脱节） |
| 真实样本契约测试 | 用实跑捕获的 stream-json 格式写测试，避免「mock 样本与真实格式不符→测试绿但实际跑挂」 |
| 路径B 执行器集成验证 | T2 验证 adapter 单独跑通后，路径B 补 executeCodeRewriteViaAgent + gitOps + postVerify + 越界回滚的真实集成，不起后端聚焦 V2.2 范式核心，成本可控 |
| 越界回滚用 git checkout | realCodeRewriteGitOps.revertFile = git checkout -- path，对 tracked 文件有效；untracked 新建文件 git checkout 无法删除（已知边界，合法改动不触发回滚） |
