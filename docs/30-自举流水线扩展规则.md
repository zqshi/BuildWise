# 自举流水线扩展规则

## 目标
让自举系统支持新增页面/API/字段等变更，并保持可验证与可回滚。

## 扩展规则（按优先级）

1. **新增页面**
- 模型：创建 `page` 节点
- 代码：生成路由 + 页面组件
- 追溯：记录 `pageId` 与组件文件锚点

2. **新增 API**
- 模型：创建 `api` 节点（method/path/schema）
- 代码：生成路由处理器 + 返回类型
- 追溯：记录 `apiId` 与路由文件锚点

3. **新增字段**
- 模型：创建 `field` 节点并绑定实体
- 代码：更新表单/表格/校验逻辑
- 追溯：记录 `fieldId` 与 UI/校验锚点

## 验证规则
- 路由存在性
- UI 显示存在性
- 规则提示与错误消息可触发

## 回滚规则
- 对应 run 记录中所有变更文件可恢复
- 新增文件在回滚中删除

## 决策日志
- 2026-02-09：确定自举流水线支持“新增页面/API/字段”三类核心变更
