## 版本计划（12 轮）

1. 版本 V0.1 统一模型最小闭环
- 目标：实体/字段/规则/页面最小结构可创建与展示
- 前端：模型编辑器基础布局、实体字段列表
- 后端：模型 CRUD API
- 验收：新增实体/字段后可在页面显示

- 后端：上传与解析记录 API
- 验收：上传后生成解析记录并展示

3. 版本 V0.3 规则编译 MVP
- 目标：自然语言规则转结构化规则

- 后端：规则编译与绑定 API
- 验收：规则可绑定字段并显示状态

4. 版本 V0.4 同步引擎 MVP
