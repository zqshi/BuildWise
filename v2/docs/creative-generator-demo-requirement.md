# 创意生成器 V1 首版本需求简报

## 产品目标
构建一个面向内容运营与市场团队的“创意生成器”Web 工具，帮助用户在单页内快速完成创意主题输入、灵感生成、结果筛选与导出。

## 目标用户
- 内容运营
- 品牌市场
- 新媒体编辑

## 核心场景
1. 用户输入产品主题、目标受众、风格偏好。
2. 系统生成多组创意标题、卖点文案和行动号召。
3. 用户对候选创意进行收藏、微调和导出。
4. 用户能够回看最近生成记录并继续迭代。

## 本轮纳入
- 创意主题输入区
- 创意结果卡片列表
- 单条创意详情抽屉
- 收藏与再次生成
- Markdown 格式需求文档与设计规范沉淀

## 本轮排除
- 多角色权限差异
- 移动端专属布局
- 外部社媒直接发布
- 团队协作审批流

## 交互原则
- 列表承载主任务流，详情通过右侧抽屉承载上下文。
- 关键交付物先只读呈现，用户明确确认后再进入下一步。
- 每次修改都通过自然语言与 Agent 协作推进。

## 关键验收标准
1. 用户能在单页完成主题输入、创意生成、收藏与再次生成。
2. 交付物抽屉默认只读，点击编辑后进入编辑态。
3. Markdown 类型交付物能正确渲染标题、列表和强调内容。
4. 原型交付物支持选择元素并通过自然语言提出调整。
5. 代码交付物以代码编辑器视图展示。
