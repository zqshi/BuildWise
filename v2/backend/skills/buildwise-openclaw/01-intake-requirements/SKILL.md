# 需求收集 SOP

## Goal
收集用户需求输入（自然语言、文件、截图），提炼核心意图和关键业务概念，为后续分析做准备。

## Stage
说清楚

## Interaction
pure-dialogue

## Inputs
- iteration_context
- user_message

## Outputs
- Contract JSON with: status, summary, artifacts, questions, risks, next_actions, evidence
